# Инструкции для Claude по этому репозиторию

## Полномочия на работу с git (с 2026-10-29, до запуска на прод)

Владелец репозитория (ADatkashov) передал Claude полное управление разработкой **без вопросов на каждый шаг**:

- Claude сам делает коммиты, пушит в ветки, открывает PR и **сам мержит в `main`** (включая собственные PR).
- Разрешение действует **до тех пор, пока владелец сам не скажет, что проект запускается на прод**. После этого сообщения
  коммиты/мержи в `main` — только с явного разрешения по каждому изменению. До этого момента не переспрашивать.
- Разрешение не распространяется на: запуск и деплой в прод, изменение настроек репозитория/секретов/переменных Actions,
  удаление веток и репозиториев, force-push и переписывание истории `main`. Это только с отдельной просьбой владельца.
- Секреты, токены и пароли никогда не коммитятся и не пишутся в PR и чат.
- Тесты не отключаются и не пропускаются ради зелёного CI. Если CI красный по причине вне кода (например, нет раннера),
  это сообщается в PR/ответе, а мерж решается по здравому смыслу и фиксируется в описании.
- Перед мержем: локально прогнать то, что можно запустить (`flutter analyze`/`test`, `./gradlew test`), и прямо сказать,
  что запустить нельзя.

Ответы владельцу — по-русски.
