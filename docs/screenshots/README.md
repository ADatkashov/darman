# Скриншоты DARMAN (демо-режим)

Сняты на реальном стеке: backend (профиль `demo`, PostgreSQL 16) + Flutter 3.47 web-сборка, вьюпорт 390×844 @2x.
Все данные вымышленные. Staff-панель снята в 1366×850 под ролью администратора.

- `mobile/` — 52 экрана приложения: онбординг, вход/регистрация, главная, поиск (в том числе «ничего не найдено»), товар, корзина (в том числе диалог «товары из другой аптеки»), оформление, заказы и трекинг,
  рецепты, профиль, адреса, избранное, уведомления, аптеки, помощь, юр. страницы, тёмная тема, казахский и английский языки.
- `staff-panel/` — 8 экранов панели сотрудников (`/admin`): вход, заказы, рецепты, предложения и остатки, товары, промо, аудит, сотрудники.
